# Old-age wealth dispersion robustness

This is the bounded Task 3 empirical check for the September 22 target review. It reuses the old-wealth block's filter and weighted-quantile convention from `build_initial_wealth.R`, on PSID waves 2003 and 2005. It does not edit targets, model code, or the literature memo.

The exact builder estimand reproduces (Q_{.90}(NETWORTHR/INCFAMR)/Q_{.50}(NETWORTHR/INCFAMR)=3.5159350865) exactly. Its person-cluster bootstrap SE is 0.30691 (499 draws, seed 20260715), matching the saved builder output. On the same 644 family-years and 416 people, the weighted p90/p50 of **NETWORTHR levels** is 4.91943 (bootstrap SE 0.57980); the weighted median and p90 are 259,332 and 1,275,768 in the shelf's real-dollar units.

Dropping the completed-children-history filter changes nothing in this window: all 650 living reference-person records age 76–84 have observed `RELCHINUM`; after the income screen both variants retain the same 644 records and 416 people. Three records are excluded for missing family income, and three for `INCFAMR <= 1000`; there are no zero- or negative-income observations in the age window. The p90/p50 of wealth levels therefore also stays 4.91943 in that variant. The builder resamples 918 people from its broader 2003/05 living-reference-person base (ages 65–84, before outcome and child-history filters), then applies the age-76–84/outcome rules inside each draw. So the reported SE reproduces the original bootstrap design; it is not an SE from resampling only the 416 final-sample people.

The requested non-asset-income denominator was not computed. The builder's selected-column contract has `INCFAMR` and `EARNINDRRC`, but not a defensible decomposition of all household labor, pension, and transfer components. Subtracting reference-person earnings from family income would not identify non-asset income, so it is not used as a proxy.

The B checkpoint is on `/scratch`; this check did not use SSH or download it. The frozen source and saved B contract suffice to establish that its old-age denominator is constant across the full selected support. The selected ages 76–84 overlap model age cells 74 (weight 0.5), 78 (1.0), and 82 (0.75), all retired cells (`j >= J_R=12`). In the frozen parameter builder, every retirement cell and location has `P.income[i,j] = P.pension`; the retirement shock scale is zero, the property-tax lump-sum transfer is zero in B, and any estate transfer applies only at ages 45–65. The observer then divides this common period pension by four, without a payroll gross-up. Thus (Y=2.0463613896/4=0.5115903474) for every selected age, location, income state, and tenure. Its asset object is beginning-of-period (W=b+pH) for owners and (W=b) for renters; this value is formed before division.

For a common positive denominator, weighted quantiles scale exactly: (Q_p(W/Y)=Q_p(W)/Y). Therefore B's reported weighted median (Q_{.50}(W/Y)=4.2641109) and p90 (Q_{.90}(W/Y)=15.8953755) imply wealth-level quantiles (Q_{.50}(W)=2.1814780), (Q_{.90}(W)=8.1319207), and (Q_{.90}(W)/Q_{.50}(W)=3.7277115), all in model units. The model p90/p50 level ratio is 1.19172 below the PSID level ratio 4.91943, or 2.05 times the empirical bootstrap SE. By contrast, the model ratio moment 3.72771 is 0.69 empirical SE above the PSID family-income-ratio target 3.51594. This establishes that the two ratio estimands differ in their level-dispersion comparison; it does not by itself attribute the close ratio-target fit to the income denominator, since sample, coverage, and asset-definition differences also remain. The model level quantities are in model units and are not dollar-calibrated.

Run from the repository root:

```sh
Rscript output/model/native_financing_diagnostic_20260919/specification_followup/target_review_v1/overnight/empirical_old_wealth/build_old_wealth_robustness.R output/model/native_financing_diagnostic_20260919/specification_followup/target_review_v1/overnight/empirical_old_wealth
```

`wealth_results.csv` contains estimates and bootstrap uncertainty; `sample_counts.csv` documents filters and income exclusions; `bootstrap_draws.csv` preserves all person-cluster draws. `input_hashes.sha256` records the raw PSID hash plus builder, current observer/annualization code, B summary and review-memo hashes. `frozen_b_source_hashes.sha256` records the pinned B parameter-builder and observer hashes that were matched to the selected run contract, plus the contract's corrected solver hash. `run_metadata.csv` records the R and package versions. The model level quantiles are recovered algebraically from its saved ratio quantiles because annual income is constant over all selected observations; the checkpoint itself was not read.
