The payroll base and worker mass remain effectively fixed because earnings and age-income transitions are exogenous in this one-market stationary experiment. Consequently, the direct PAYGO calculation already predicts the pension nearly halving when the tax halves. **Aggregate wealth is a stock; the run does not measure a saving flow.** Wealth, housing and fertility changes are equilibrium responses under fixed preferences; this two-case run does not isolate each mechanism. It does show that the proposed rate is a substantial economic change, not a cosmetic calibration adjustment.

The source variable `legacy_moments.tfr` is calculated from the post-fertility household-head distribution: mean children ever born, with the three-or-more state weighted at `3.602359422009`. Under the current stationary operator it also equals top-code-adjusted birth flow divided by entry flow (E): `0.1296682858 / 0.0617334562 = 2.100454` and `0.1390294875 / 0.0617334562 = 2.252093`. Entry flow (E) stays fixed across cases. Thus this is a **stationary household and market solve conditional on the existing entry/maturation law**, not a newly normalized demographic steady state, a period total fertility rate, or observed cohort completed fertility. The source `legacy_moments.mean_completed_fertility` is the raw post-fertility children-state mean that weights the top state at three: 1.883 to 2.012.
