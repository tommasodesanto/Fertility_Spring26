# Quarter-saving fixed-price benchmarks, v1

This experimental partial-equilibrium packet evaluates the quarter-saving buyer rule at financed shares \(\phi=0.8\) and \(\phi=1\), applied to both buyers and owner-stayers. Define available wealth \(A=b+S\), where \(S\) is net proceeds from selling the current home; transaction balance \(x=A-Q\); and current net saving \(s=b'-x=(R-1)x+y-c-K\). Buyer eligibility requires \(A+0.25s\geq(1-\phi)Q\). Equivalently, the buyer Bellman choice uses \(b'\geq b_f+3\max(0,b_f-x)\), with \(b_f=-\phi Q\). The original soft purchase screen remains; the forward map \(x=b+S-Q\), interest timing, and stayer saving rule are unchanged. \(\phi=1\) means zero required down payment, not unlimited debt.

Both cases hold the strict-80 reference's ten calibrated coordinates, price **0.7152515073815459**, housing-supply coefficient **\(H_0=6.778473404808042\)**, and initial population **\(N_0=1\)** fixed. Entry, preferences, targets, weights, other bounds and fiscal rules are unchanged. Birth replacement and the housing-market residual are measured rather than cleared; these are not general-equilibrium calibrations. The driver requires 14 target rows, 31 parameter rows, 17 standard plots and the native cohort, feasibility, renter and PAYGO checks in each case. From a fresh frozen-runtime mount, `python3 run.py --out /work/results/newrun` regenerates the cases and their standard plot packets; the staged Torch launcher provides that runtime with one CPU, 24 GiB and a 20-minute cap.
