# Local authenticated runtime for the two purchase-rule searches

This folder keeps the September 28 frozen reference authenticator intact while running the new hard and quarter-saving engines on the Mac. The pinned native source inventory has 1,241 files. Exactly two live files currently differ from it: `code/model/tools/e5f_exact_policy_cache.py` and `code/model/tools/test_e5f_exact_policy_cache.py`. Their authenticated frozen bytes are copied into `frozen_sources/`. `bootstrap.py` redirects read-only file access and Python source loading for only those two absolute paths. It verifies both SHA-256 hashes before importing the search. Writes to those paths are rejected. All ordinary source, engine, target and frozen-context authentication continues to run.

The zero-solve context preflight passed for hard chain 0 and quarter chain 24 using `code/model/.venv/bin/python`. Each pass authenticated the packet manifest, 157 engine source pins, 234 multistart source pins, and the frozen context, then built the normalized evaluator without calling a household or equilibrium solver. Receipts are `preflight_chain0.json` and `preflight_chain24.json`. Regenerate one with:

```bash
OMP_NUM_THREADS=1 NUMBA_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 MPLBACKEND=Agg code/model/.venv/bin/python output/model/fixed_reference_economics_20260928/purchase_rules_overnight_v1/local_runtime/bootstrap.py --preflight-context --chain 0
```

`launch_one.sh` runs one search and then verifies its selected candidate in a fresh interpreter under the same absolute four-hour deadline. Each `chainN/` directory contains `search/`, `postcheck/`, and `worker_terminal.json`; a completed search alone is provisional. `launch_batch.sh` starts a detached two-worker ramp toward ten workers with one thread each, a first-useful-case and memory gate before each additional pair, and an eight-hour hard cap. It writes `runs/local10_v1/latest_progress.json` and `terminal.json`. The explicit launch command after lead review is `ALLOW_LOCAL_CALIBRATION=1 bash output/model/fixed_reference_economics_20260928/purchase_rules_overnight_v1/local_runtime/launch_batch.sh`. `caffeinate -i`, where available, inhibits idle sleep while the supervisor runs; closing a laptop lid may still suspend the run.

The Mac reports 18 physical CPUs (6 performance and 12 efficiency) and 48 GiB unified memory. Recent single-core Torch jobs peaked at 2.47–3.78 GiB RSS; the two corrected 100% fixed-price jobs peaked at 2.51 and 2.78 GiB. Ten simultaneous workers could use roughly 25–38 GiB of worker RSS before operating-system, app, and Numba-cache overhead. That leaves little margin at the 3.78 GiB upper observation, so a ten-worker Mac launch needs live memory-pressure checks and a stop rule. These are cross-machine planning figures, not a measured Mac peak.
