# Hard zero-down fixed-price diagnostic

This experimental partial-equilibrium case uses the completed strict-purchase 80% reference. It changes only the financed share $\phi$ from 0.8 to 1.0 in all four housing products, for buyers and owner-stayers. Thus the purchase down-payment threshold $(1-\phi)pH$ is zero for each product. The strict beginning-of-period wealth rule and all other credit caps, income timing, sale proceeds, budget, preferences, calibrated coordinates, targets, weights, grids, and accounting checks remain unchanged. This is neither a new equilibrium nor a recalibration.

The housing price is fixed at 0.7152515073815459, physical housing-supply coefficient $H_0$ at 6.778473404808042, and initial physical population $N_0$ at 1. There is no price root, housing-market clearing, or fertility normalization in this new solve; renewal and housing residuals are measured. The original strict-purchase engine is mounted unchanged. The three small files in `input/strict80/` are copied from the completed strict-purchase credit packet and checked against its fingerprints. The fixed-price observer and phase source variants are emitted with diffs.

`run.py` executes one new $\phi=1$ lifecycle solve and writes the native 14-row target fit, 31-row parameter table, 17 standard plots, closure data, source-review receipt, `latest_completed.json`, and `completed.json`. Existing strict-80 and validated 80% fixed-price replay results are reused; there is no exploratory repeat. `completed.json` records `repeat_performed=false`, `exploratory_no_repeat=true`, and one lifecycle solve.
