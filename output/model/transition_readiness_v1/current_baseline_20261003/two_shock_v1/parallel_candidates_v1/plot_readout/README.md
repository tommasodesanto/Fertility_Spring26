The plotter accepts the current-estate saved native dated JSON, its matching completion receipt, and the fresh-reference initial summary and stationary JSON. It checks row identity, four-year dates, initial housing and price normalization, finite plotted series and root/replay gates. It requires a constant dated preference for a first-shock receipt; a receipt explicitly marked `two_shock_result: true` may have a dated preference path. `--allow-incomplete` permits an incomplete saved path and records that status in provenance. `--targets` adds observed values when a matching contract is available. The previous panels remain cached supplemental artifacts; the default command generates only the September 14 pair.
