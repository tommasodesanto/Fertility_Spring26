Minimal feasible carrying strategy: factor the nested law as
\[
p(\tau,a\mid x)=p(a\mid x)\,p(\tau\mid a,x),
\]
but carry it as a **joint plan object**, not two unconditional arrays. Split the pre-choice mass into action branches; apply conception to each branch; then invoke the existing realization/aging kernels separately with that branch’s \(p(\tau\mid a,x)\), summing only after tenure/product transaction and wealth scattering. The current interfaces can support this mechanically through repeated branch calls, but the Bellman/forward contracts need an added action axis or equivalent `joint_plan_probs`. For the experiment’s commitment rule, the object must also retain the chosen tenure through success/failure; outcome-specific owner-product policies need to be passed with the branch. Current `tenure_probs` alone is indexed by post-choice family state and is insufficient.

Existing closure: this is a rolling, contemporaneous temporary-equilibrium transition, not perfect foresight. Each date solves the household Bellman at that date’s candidate price ([run_dynamic_population_transition.py:316](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/code/model/tools/run_dynamic_population_transition.py:316)–[342](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/code/model/tools/run_dynamic_population_transition.py:316)), clears current demand against static supply, then uses the cleared policy as the next date’s warm start. The canonical status explicitly says households use temporary-equilibrium expectations and this is “not a perfect-foresight asset-price transition” ([CALIBRATION_STATUS.md:1442](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/CALIBRATION_STATUS.md:1442)–[1471](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/CALIBRATION_STATUS.md:1442)). A perfect-foresight sequence would require value functions conditional on the whole future price path, not this rolling price solve.

Top silent-invalidity risks:

1. Updating the Bellman probabilities but retaining fertility-then-tenure forward scattering.
2. Reconstructing the inherited stationary/2007 state with the old operator while measuring the transition with the joint operator.
3. Letting the first-birth event-study branch redraw tenure after success/failure, destroying treated-group selection.
4. Treating the rolling current-price closure as a perfect-foresight sequence.
5. Dropping continuation-birth joint plans: `fert2_probs` governs parity \(1\to2\) and above, so a first-birth-only integration would leave long-run births, queue entries, and target measurement internally inconsistent.

The status remains clear that the one-date nested result is fixed-price/frozen-continuation only and that full lifecycle, clearing, and target reassessment are outstanding ([CALIBRATION_STATUS.md:7](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/CALIBRATION_STATUS.md:7)–[42](/Users/tommasodesanto/Desktop/Projects/Fertility/Fertility_Spring26/CALIBRATION_STATUS.md:42)).
