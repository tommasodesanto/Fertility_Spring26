# JMP_DS_draft

This is Tommaso De Santo's author-controlled job-market-paper manuscript. The
main file is `JMP_DS_draft.tex`; visible manuscript text is split across the
files in `sections/` and `appendices/`.

Agents and assistants have read access only. Proposed material must be placed
outside this directory, in `../JMP_DS_suggestions/`, for manual copy-and-paste
by the author. See `AGENTS.md` for the full guard rule.

For an agent-side compilation check, first copy the source tree and its linked
bibliography and figure inputs to a temporary directory, then compile that
temporary copy. Agents must never compile the protected source tree in place.
