# October 7 result tables (v4)

Mechanical table fragments for the October 7 experiments. The experiments use the stated fixed-price normalization and do not recalibrate. Rebate treatment varies by comparison: fp_price110 rebalances the rebate, while A6_P110 holds it fixed. The cap-five plus parent-space-floor-two case is an illustration. Coverage of unspecified project-files tables remains pending.

## Generate

From the project root on a new destination:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 code/model/tools/build_jmp_result_tables_v4.py --output-dir /absolute/new/destination
```

Supply additional Markdown or CSV inputs by repeating `--project-table PATH`.
