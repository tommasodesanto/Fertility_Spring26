# Person-cohort demographic transition

This isolated package is the replacement boundary for the E5F
`births / 2.1 at age 20` household-renewal queue. It is not yet imported by the
active perfect-foresight solver.

`person_cohort_law.py` advances resident persons by sex and single year of age.
Births, survival, and net migration are separate inputs. Household heads are a
separate stock generated by explicit nonhead-to-head formation, head
dissolution, and migrant-head flows. Every annual step reports and checks the
person and head accounting identities.

The current headship closure uses fixed 2023 ACS age-sex rates and the minimum
one-way gross flow needed to attain each rate. It is deliberately an accounting
closure, not an estimated behavioral hazard. The next integration stage must
preserve those separate flows even if a richer formation model replaces it.

`household_head_bridge.py` is the isolated interface to the lifecycle model.
It aggregates single-year heads into four-year model ages and rescales the
within-age household distribution to those masses while preserving its
conditional economic-state composition. Every addition and removal is exposed
in a separate ledger; this proportional-composition rule is provisional.

Run the unit tests from the repository root:

```bash
PYTHONPATH=code/model code/model/.venv/bin/python -m unittest discover -v \
  -s code/model/demographic_transition/tests -p 'test_*.py'
```

Canonical isolated packets:

- `output/model/e5f_coherent_person_cohort_path_20260826a/`
- `output/model/e5f_coherent_terminal_demographic_diagnostic_20260826a/`

The first reproduces the Vintage-2025-anchored Census/ACS demographic path and
writes four-year household-head bridge files. The second evaluates the current
and old queue-based terminal birth rates against the corrected demographic
fixed point. Neither packet changes the certified baseline or slide files.
